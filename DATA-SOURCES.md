## Export behavior

Every selected ranking fits in one image using featured top-three cards and adaptive columns. Desktop offers nine sizes, PNG/JPG/WebP and All/Top 10/Top 25. Mobile offers 1:1, 3:4, 4:5 and 9:16, automatic PNG and the same ranges. Pagination and ZIP controls stay hidden. Dense formats use smaller text; full player names are retained.

Cards are generated in the visitor’s browser without uploading rankings. Mobile uses a ready PNG file for native sharing and a real PNG preview for press-and-hold saving. Actual iPhone Photos menus still need physical-device validation. Missing or CORS-restricted portraits use jerseys. Generating a card does not confer additional image rights.

## Weekly verification and historical rosters

The frozen figures and dates above document the initial snapshots. Current data is supplied by `weekly-rosters.js`, loaded after those baseline files. The scheduled GitHub workflow checks both sports each Tuesday at 08:00 America/New_York and records per-team results in `assets/roster-refresh-status.json`. Scheduled jobs can be delayed by GitHub; verification dates advance only for successfully checked teams.

NFL rosters use each team's official Active table. NBA rosters use NBA.com's structured roster array, including supplemental/two-way players listed there. Player names, official team identity, allowed positions, unique identities, reasonable roster counts and headshot provenance are checked. Existing NFL identities are matched first by full official profile URL, then an unambiguous same-team name; newly added or ambiguous same-name players receive distinct source-derived IDs. A shared name alone never merges players on different teams. The Vega Ioane headshot correction remains in place.

NBA.com is the primary portrait source. Missing, failed or known generic NBA images use an unambiguous player match in ESPN's roster for the same team. Public image availability still does not establish an independent redistribution license, endorsement, or guarantee that a provider has updated every uniform. New NBA PNGs are stored immutably under `assets/roster-headshots/` with source metadata and SHA-256 hashes in their records. NFL headshots continue to use official remotely hosted portraits.

Previous roster snapshots and their portrait mappings are archived before replacement. Existing shared links select their original roster through `assets/roster-snapshots/index.json`; malformed or unavailable snapshots never replace a recipient's own ranking. Existing browser progress can continue with its original players. Switching to the newest roster archives the previous ranking locally rather than silently adding, deleting or reordering players.

A failed team source, unresolved new portrait or unexpected roster reduction retains the team's last published roster and date. Cross-team identity conflicts retain the whole affected league. Candidates publish only after data and browser checks; failures leave the live site intact. The first deployment is a validated refresh, and subsequent runs follow the Tuesday schedule. All work takes place on GitHub.
