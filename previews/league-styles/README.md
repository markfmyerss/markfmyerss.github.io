# League style trial

Opt-in NFL and NBA visual design trial. Open [NFL](https://markfmyerss.github.io/previews/league-styles/?sport=NFL) or [NBA](https://markfmyerss.github.io/previews/league-styles/?sport=NBA).

NFL uses navy/red, condensed type and field markings; NBA uses royal blue/red, wider typography, round controls and court geometry. Team colors remain on cards and Choose favorite buttons. All three appearances work.

This route is separate from the production design. It reuses current live data and exports but snapshots the current application and appearance logic for the trial. All preview preference and ranking keys are prefixed with fan-favorites-league-style-trial-v1:; existing live rankings are neither read nor changed. Shared preview results keep the preview path. The root index, app, styles, data and appearance files are unchanged. The page is marked noindex/nofollow and is not linked from the main navigation. No promotion to the official design has been approved.

Browser checks on GitHub covered Chromium/WebKit, 320–1440px, Light/Dim/Lights Out, sorting/undo/reload, position filters, team button colors, single-image exports, and preservation of all live-site storage entries. This is an independent fan project; league branding cues do not imply affiliation. Artwork is code-native field/court geometry.
