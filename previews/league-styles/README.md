# League style preview

The NFL and NBA styles were approved and promoted to the [main site](https://markfmyerss.github.io/), using the original headline: **Your teams. Your favorites.**

The [NFL preview](https://markfmyerss.github.io/previews/league-styles/?sport=NFL) and [NBA preview](https://markfmyerss.github.io/previews/league-styles/?sport=NBA) remain separate sandboxes. Their ranking and preference keys use fan-favorites-league-style-trial-v1: and never read or modify live-site rankings. Preview sharing links retain the preview path. The preview is not linked from the main navigation and remains marked noindex/nofollow.

Production uses league-style.css and league-style.js with the original app.js and existing save keys. NFL: navy/red, condensed type and field markings. NBA: royal blue/red, wider typography, round controls and court geometry. Team colors remain on cards and Choose favorite buttons. Light, Dim and Lights Out are supported. This remains an independent fan project.
